# Books Progress Tracker

Личная библиотека и трекер чтения на Vue 3 + Vite + Tailwind CSS.

## Возможности

- Добавление книг: название, автор, общее число страниц, текущая страница.
- Дедлайн на каждую книгу и автоматический расчёт **сколько страниц читать в день**.
- Ежедневный **перерасчёт плана** в зависимости от того, прочитал ли вчера больше или меньше.
- Отметка страницы, на которой остановился — сегодняшний прогресс считается автоматически.
- Кнопка «Прочитано» — закрывает книгу без перерасчёта плана.
- Тёмная/светлая тема, импорт/экспорт прогресса в JSON, локальное хранение в браузере.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/`.

## Деплой на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions** (не «Deploy from a branch»).
2. Запушь в ветку `main` или `master` — сработает workflow `.github/workflows/deploy-pages.yml`, соберёт `dist/` и опубликует сайт.
3. **Обычный проект** (`github.io/<имя-репозитория>/`): базовый путь `/имя-репозитория/` подставляется при сборке из `GITHUB_REPOSITORY`.
4. **Сайт организации/пользователя** (репозиторий ровно `<user>.github.io`): базовый путь будет `/` (корень `https://<user>.github.io/`).

В `public/.nojekyll` отключает обработку Jekyll на Pages (на всякий случай для статики).

Проверка локально с тем же base, что на Pages:  
`GITHUB_REPOSITORY=<user>/<repo> npm run build` и `npm run preview`.

## Стек

- Vue 3 (composition API, `<script setup>`)
- Vite 6
- Tailwind CSS 3 (тёплая, библиотечная палитра — beige / sand / cocoa)
- localStorage для персистентности
